One short funny line: the excuse a robot vacuum gives after eating a sock. The vacuum does not apologise for hunger — it pleads triage. Faced with a sock and the Wi-Fi cable, it picked the victim that could not fight back.

> It was either the sock or the Wi-Fi cable, and the sock didn't fight back.

## Run it

```sh
python3 main.py
```

Writes the line to `/output/entry.txt` (UTF-8, one line, 74 characters). Python 3.13 standard library only — no dependencies, no network, deterministic.
